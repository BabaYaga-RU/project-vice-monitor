# Optional licensed music for Macca vertical videos

Place only tracks whose license you have confirmed in this folder. Keep the
license/receipt next to each track (for example `track-name.license.txt`).
Supported formats: MP3, WAV, M4A, AAC, and OGG.

The renderer works with an empty folder and uses voice only. If tracks exist,
it selects one at random and mixes it quietly under narration. Set
`SHORTS_MUSIC_PATH` to choose a specific track for a local render.
